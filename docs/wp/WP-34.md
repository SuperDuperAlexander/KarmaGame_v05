## Tasks

1. Write `tools/rig/rig_shared.py`. Input: one character GLB. Output: the same mesh, material and texture, skinned to the 17 bones with the same names and parents as the player rig, plus the same five clips.
2. Joint marks per character: fit the 17 player marks to each mesh. Scale by measured height. Then correct hips, shoulders, elbows, hands, knees and feet from mesh slices (width and center of the body at each height). Store the final marks per character in `tools/rig/marks/<name>.json`, so a person can fix one mark by hand and run again.
3. Clips: reuse the v2 clip generator with each character's marks. Bone rotations stay the same. Scale hip motion and step reach by leg length. Walk stays authored for 2.8 m/s, Run for 4.6 m/s.
4. Keep `leftHandGrip` and `rightHandGrip` as children of the hand joints (same as v2). Keep source node names that the registry uses.
5. Keep limits: 45 bones or fewer, 4 weights per vertex, no root motion, no scale keys, 30 keys per second or more. Each output 3 MB or less.
6. Write `tools/rig/validate_shared.py` (based on `validate_rig_v2.py`) and run it for all six. Save `tools/rig/validation-shared.json`.
7. Registry (status `temporary`): point `Merchant`, `Citizen`, `CitizenMale`, `FearChild`, `DarkNpc`, `ExchangeGuide` to `/assets/characters/<output>`. Clip map `idle`, `walk`, `run` (fallback walk), same as `Player`. Nodes `handR`, `handL`.
8. `src/npc/merchant.ts`: play the `idle` clip instead of the code sway when the clip exists. Keep the code sway as the fallback for placeholders.
9. Render one image per character in `docs/evidence/wp-34/` (front view, mid-walk view). Use your own dev server port.
