# WP-31: Asset optimizer

- Model: Claude Sonnet. Wave 1. Needs: WP-30.
- Read `docs/wp/_COMMON_FINISH.md` first.
- Owns: `tools/assets/`, `tests/assets-tools*.spec.ts`.
- Allowed exception: add devDependencies `@gltf-transform/core`, `@gltf-transform/extensions`, `@gltf-transform/functions` and, if needed, `sharp` to `package.json` and the lockfile. Nothing else in package files.

## Goal

`npm run assets:sync` writes optimized copies of `3D Models/assets/**.glb` to `public/assets/`. Source files stay unchanged.

## Tasks

1. Keep the sync contract: same output paths. Idempotent: skip a file when source hash and settings are unchanged. Keep a small cache manifest in `public/assets/`.
2. Optimize with glTF-Transform: dedup, prune (keep empty named nodes such as grips and `linkStart`), weld, resize textures (max 1024 px; 512 px for `package_chain`), convert textures to WebP (`EXT_texture_webp`; Babylon loads it natively). Use `KHR_mesh_quantization` only if Babylon loads it with no extra decoder.
3. Do NOT use meshopt or draco compression (they need decoders). Do NOT flatten, join, rename or reparent nodes. Node names are the registry contract.
4. Keep copying `character-rig-test/public/player_rigged_test.glb` as today. Optimize `player_rigged_v2.glb` too, but keep skin and animation data intact.
5. `npm run assets:check`: add columns raw MB, optimized MB, texture px. Print totals. Warn when the total is over 35 MB.
6. Fail safe: if one file fails to optimize, copy the raw file and print one warning.

## Done when

- The report gives the optimized total of `public/assets/` (target 15 MB or less) and a before/after table per file.
- A node check proves every node name of every source file still exists in the output.
- `npm run test:e2e` passes with the optimized files (it loads them in Babylon).
