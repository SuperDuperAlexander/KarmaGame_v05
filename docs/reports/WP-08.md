# WP-08: Thought waves

- Added `src/thought-waves/index.ts` and `src/thought-waves/core.ts`.
- API [application programming interface]: `createWaveService(scene, root): WaveService`.
- A wave uses one small 3D ribbon and one plain-text screen label.
- The ribbon has 17 points per edge. Its warm gold color shows attachment.
- Waves last four seconds. Two waves can be active at once.
- Empty text and text above 64 characters are rejected.
- A service remembers each accepted wave ID [identifier], even after the wave ends.
- Labels stay inside screen margins and above touch controls. Waves behind the view hide their label.
- Reduced motion keeps the ribbon still. Opacity still fades.
- Dispose removes labels, meshes and materials.
- Tests cover limits, repeated IDs, label clamps and fade bounds.
- `npm run typecheck`, `npm run lint` and `npm test`: passed.
- `npm run build`: blocked by missing lead-owned `src/main.ts`.
- Keep the outer-world wave service alive across visits. Create a new service for New Game.
- Saved rules must prevent the wave after page reload. This worker does not own save or rules.
- The lead must run visual and browser checks.
