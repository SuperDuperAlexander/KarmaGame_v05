## Use

- Import `createSaveService`, `SAVE_KEY` and `RECOVERY_KEY` from `src/save/index.ts`.
- `load()` returns checked state or `null`.
- The lead puts loaded state into the store before play starts.
- State updates request a save by themselves.
- `flush()` returns `false` when it must wait or storage cannot write.
- A delayed flush keeps its pending write.
- The lead must wait for `flush()` before it starts the desire wave.
- Limit retries if storage cannot write.
- `clear()` removes the active and recovery keys.
- `saveReflection(store, text)` writes the `money` text entry.
- `skipReflection(store)` removes the `money` text entry.
- Dispatch `reflection-done` after either helper.
- `deleteReflections(store)` removes all text entries.
- The screen must show the text with `textContent` or `textarea.value`.
- A recovery key can still hold old words after a bad save. The lead must clear that key when the user asks to delete all words.
