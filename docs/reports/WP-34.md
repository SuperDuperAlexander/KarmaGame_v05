# WP-34 report: shared rig and clips

## Done

- All six characters use the 17-bone rig and the five clips of the test rig.
- Clips: `Idle`, `Walk`, `Run`, `Interact`, `LookAround`. Same bone names and parents as the player.
- Tools: `tools/rig/fit_marks.py`, `rig_shared.py`, `validate_shared.py`. Python standard library only.
- Marks: `tools/rig/marks/<name>.json`. A person can edit one mark and run the tools again.
- Registry: `Merchant`, `Citizen`, `CitizenMale`, `FearChild`, `DarkNpc`, `ExchangeGuide` point to the new files. Status `temporary`. Clip map `idle`, `walk`, `run`. Nodes `handR`, `handL`.
- `src/npc/merchant.ts`: the code sway runs only when the idle clip is missing or the asset is a placeholder.
- Test: `tests/rig-shared.spec.ts`.
- Evidence: `docs/evidence/wp-34/<name>_front.png` and `<name>_walk.png` (Babylon render, own port 5234).

## Marks

- Method: scale by measured height, then slices. Arm line from the outer arm edge. Leg centres from slices at ankle and knee. Hip height from the crotch gap. Torso z from the centre column. Each measure is calibrated on the player mesh.
- Corrected by hand: `fear_child` only. Its head is large and its legs are short. Set in `params`: shoulder, hip, knee, ankle, spine, chest, neck and head heights.
- `exchange_guide`: the long coat hides the crotch. Hip height stays at the scaled player value.
