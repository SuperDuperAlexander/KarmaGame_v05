# WP-05: Input and touch controls

- Added `src/input/index.ts` and `src/input/state.ts`.
- API [application programming interface]: `createInputService(canvas, touchRoot): InputService`.
- Keyboard move uses W A S D and arrow keys. Shift runs. E gives one press and a held state.
- Each read clears press, view drag and wheel data.
- The touch stick appears after a real touch. It uses pointer capture and a radial dead zone.
- Run and Act have targets of at least 64 pixels.
- The stick and view drag use separate pointer IDs [identifiers].
- Locks use unique tokens. The same lock name can be used twice. Each lock release clears held data.
- View drag supports left mouse, right mouse and touch. The app must clamp camera pitch and distance.
- Blur and page hide clear held data. Dispose removes all owned listeners and controls.
- `npm run typecheck`: passed.
- `npm run lint`: passed.
- `npm test`: passed. Eight tests cover input and wave rules.
