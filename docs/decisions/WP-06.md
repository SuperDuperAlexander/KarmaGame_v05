# WP-06 decisions

- Use page elements for menus and text. Use no Babylon imports in the user interface.
- Render supplied text as plain text. Never parse it as HTML [Hypertext Markup Language].
- Keep reflection, pause and confirm in one modal. The app still owns all state and save commands.
- Focus the textarea only when the app opens reflection after an explicit action.
- Keep touch controls in their own root. The user interface never clears that root.
- Put the prompt at least 158 pixels above the bottom safe area. The touch controls use the lower space.
- Keep the load lock separate from the modal lock.
