# WP-03 [Work Package 03] decisions

- Keep saves on the device with `localStorage`.
- Use `light-within-save-v1` for the active save.
- Use `light-within-save-recovery` for a bad save.
- Accept only the current shape and the known version zero shape.
- Version zero is the same state without once names and wave names.
- Reject later versions safely.
- Bound positions, traits, counts, keys and text.
- Reject unsafe object keys.
- Keep text literal. Do not read it as markup.
- Use a one second write gap for normal requests and `flush()`.
- Force a pending write at page hide or service close.
- Clear cancels queued writes and removes both storage keys.
- Reflection helpers do not set game facts.
- The caller sends `reflection-done` after Save or Skip.
