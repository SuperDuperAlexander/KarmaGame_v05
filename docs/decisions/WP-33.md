# WP-33 decisions

- Tree size. The tree file is 25 x 30 m, with root feet in a ring. At scale 0.55 the roots covered the package and beetle. At scale 1.2 the ring sits at the blocker. I chose 1.2.
- Mirror and turn. The glTF loader flips X, so attachment roots came out west. I mirror X on the tree node. I turn it -40 degrees. A scan of the vertices showed no root feet at the four gameplay spots.
- Chain. Real link has 1,500 triangles. 15 links cost about 22,000 triangles. This fits the budget. Links are instances of one mesh: one draw call. Placeholder mode keeps the old merged torus chain.
- `createChain` stays. The outer scene manager calls it. I did not change shared files.
- Materials. The tree has one material. I clone it for attachment roots and for fear roots. This costs no extra draw call (each root is already its own mesh).
- Fear roots. The texture is already cold and dark. I add only a faint blue light.
- Beetle glow. I copy the material and use the albedo texture as emissive. Only the gold veins glow. Glow level follows `traits.attachment`.
- Floor. I kept the code disk. Kit platforms are 8 m or less, so they do not tile r 11.
- Status of all new entries: `temporary`.
