# WP-35 decisions

- Textures are drawn in code (canvas). No new files, no download cost. A seeded random function keeps the look the same on every load (AD-9). With no canvas (unit tests) the old flat colours stay.
- Path edges fade by texture alpha, not by extra meshes. The same meshes and colliders stay. No extra draw call.
- On a box top, u runs along Z and v along X. Wrap is on along the path and clamp across it. I found this by a streak bug.
- The carved inner stone uses `useEmissiveAsIllumination`. Without it, a dark diffuse texture hides the glow (emissive is multiplied by the diffuse colour).
- Roots from the tree file are almost black. A flat blue glow is cheaper and safer than a texture glow. Hemispheric ground colour (cyan) lights roots from below, with no second dynamic light.
- One sun, one hemispheric light only. The shadow generator follows the player. Only ground receives shadows. Casters are chosen by node name and capped at 12 meshes. Small leaf parts are left out.
- Sky is a shader dome with no texture. Fog colour equals the horizon colour, so the world edge melts into the sky.
- Source Water is a custom ribbon with 2 vertices per step. Shader makes the soft edges and ripples. Specks are billboard particles (not merged spheres as before).
- Inner water ends at x -7.4, z -4.4. Fear root feet stand at x -2 to -14, z -4 to -14 (measured from root meshes). The old strip crossed them.
- Quality: parts call `onQuality(scene,handler)`. `setPresentationQuality` calls them all. This does not touch state. `app.ts` needs no change.
- Leaf and root glow read only state (attachment, TREE_DISCOVERED). The one-time pulse is a short effect, not a lasting look.
- The carry chain is built at 2x size and scaled to 0.5. This reuses `createInnerChain` without a change in `src/props/chain.ts`.
- Outer arrival path box is 36 m long (was 30 m) so the path reaches the square. It has no collider. Gameplay did not change.
