# WP-41 decisions

- The dark shape was the camera fade, not a mesh. The tree material is OPAQUE, so `mesh.visibility` did nothing. I set `transparencyMode = null` on the tree materials. This is a small change in my own file. I did not move any root.
- Far islands, crystals, plants and the rock skirt are code-made flat-shaded meshes with baked vertex colour. One merged mesh each, so few draw calls. They use an unlit material with an emissive colour, so they need no light and the glow layer can use them.
- Kit platforms are not repeated for the backdrop. Each kit part is a separate draw call and carries 2000 to 3500 triangles.
- The nebula is one shader on a dome. No texture file. Stars are a hash grid.
- Waterfalls are one merged ribbon mesh with one scrolling shader. Mist is one particle system with 14 slots.
- Crystals near the camera side stay low. Tall crystals filled a third of the screen in the first test.
- Gold roots use a flat low emissive. A high value made them look like flat tan paper. The glow layer should add the shine later.
- Story spot discs stay (the interaction code may use them) but they are now tinted and see-through.
- Outer water is unchanged. Inner brightness is switched by `step(0.5, glow)` in the shader.
- The `?debug` scene hook was not added to `app.ts`. I used it only for local tests and reverted it.
