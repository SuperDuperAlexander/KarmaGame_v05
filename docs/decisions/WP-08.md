# WP-08 decisions

- Use a four-second wave. The master allows 2.5 to 5 seconds.
- Use a low-cost ribbon with no lights and one material. The label stays clear through screen-edge clamps.
- Count Unicode characters, not bytes. Reject more than 64 characters.
- Store used wave IDs [identifiers] in the live service. The rule/save layer owns reload protection.
- Keep reduced-motion movement at zero. Fade opacity in and out.
- Read view-space depth to hide labels behind the camera. This needs no Ray module side effect.
