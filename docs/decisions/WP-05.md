# WP-05 decisions

- Use a pure input state class. This makes lock and press rules testable without a browser.
- Use one token per lock call. A shared reason name must not unlock another owner.
- Clear held data on lock, release, blur and page hide. The player must press again after a menu closes.
- Use normalized move values. The lead maps forward and right to camera direction.
- Use a radial touch dead zone of 0.16. Clamp stick length to one.
- Use pointer events and pointer capture. This supports a stick and action touch at the same time.
- Keep camera clamps in the app camera code.
